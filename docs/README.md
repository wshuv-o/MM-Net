# Project page

Served at https://wshuv-o.github.io/MM-Net by GitHub Pages from this folder.

Built on the [Nerfies project page template](https://github.com/nerfies/nerfies.github.io)
by Keunhong Park and colleagues, which is released under CC BY-SA 4.0. `static/css/index.css`
and the page structure come from that template; the footer carries the attribution
their licence asks for.

Bulma, FontAwesome and Academicons load from CDNs rather than being vendored.

The manuscript is not hosted here while it is under review. Model weights are
attached to a GitHub release rather than committed, so a clone stays small.
